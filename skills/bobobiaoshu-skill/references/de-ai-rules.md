# 去 AI 痕迹速查规则

标书去 AI 痕迹的快速参考。完整理论指南见 `humanizer-zh.md`，本文件聚焦可操作的替换规则。

---

## 一、红旗词词典（直接查找替换）

### 1. 转折连接词（直接删除）

以下词汇零信息量，直接删除不影响语义：

- 值得注意的是 / 需要注意的是 / 需要指出的是
- 综上所述 / 总的来说 / 整体来看
- 在这个过程中 / 在此基础上
- 不难发现 / 由此可见 / 毋庸置疑
- 不可否认 / 众所周知 / 显而易见
- 从某种程度上说 / 从某种意义上讲
- 换句话说 / 也就是说（冗余时）

### 2. 模糊限定词（替换或删除）

| AI 用法 | 人工替换 |
|---------|---------|
| 可能会 | 会 / 可能 |
| 也许 / 或许 | 直接删除或陈述事实 |
| 在一定程度上 | 删除，直接陈述 |
| 有待进一步验证 | 还需验证 / 待验证 |
| 存在一定的可能性 | 可能 |
| 可以说是 | 是 |
| 通常是 | 一般是 / 多数是 |
| 不能完全排除 | 也可能 |

### 3. 结构填充词（直接删除）

- 首先...其次...再次...最后... → 改为自然过渡或简单列表
- 一方面...另一方面... → 简化为直接对比
- 从XX角度来看 → 删除，直接陈述分析
- 关于XX，可以从以下几个维度来看 → 删除，直接列点
- 下面将从XX方面进行分析 → 删除，直接开始分析

### 4. AI 高频词汇（替换或删除）

- 此外 → 删除或用"另外"
- 不仅...而且 → 拆分为两个独立陈述
- 深入 / 深刻 / 充满活力 → 删除
- 关键性的 → 关键的
- 不断演变的格局 → 删除整句
- 为...奠定基础 → 删除或具体说明
- 不可磨灭的印记 → 删除
- 标志着 → 删除或改为"是"

### 5. 元自指（直接删除）

- 作为AI / 作为人工智能 / 作为语言模型
- 以上内容仅供参考 / 希望对您有帮助
- 如果您还有其他问题，欢迎随时提问

## 二、结构去模式化

### 打破对称列表

```
AI 写法（完美对称）:
- 方案一：建立数据中台，实现数据整合
- 方案二：优化业务流程，提升运营效率
- 方案三：引入AI技术，推动智能转型

人工写法（长短不一）:
- 建数据中台，先把数据打通
- 流程该优化的优化
- AI 可以试，但别指望一步到位
```

### 打破对称段落

AI 倾向于每段句数相同、每句字数相近。人工写法应变化：一段 2 句，下一段 6 句，再下一段 3 句。

### 打破从句配对

```
AI: 不仅提升了效率，还降低了成本，同时保障了质量
人工: 效率提上去了，成本也省了，质量没掉
```

## 三、语气自然化规则

1. **缩短句子**：超过 25 字的句子考虑拆成两句
2. **用口语化表达**：给→搞/弄, 进行→做, 实施→干, 开展→上
3. **加转折词**：偶尔用"其实""说白了""坦白讲"
4. **变化节奏**：不要每句都是"主语+动词+宾语"，偶尔倒装、省略主语
5. **用具体数据**："降低了30%" > "大幅降低"；"3天完成" > "尽快完成"
6. **不追求面面俱到**：真人不会每个观点都两面论证，可以只说一边
7. **使用行业术语**：如果是行业人士，用行话代替解释性语言

## 四、标书专项检查

### 禁止出现的内容

| 检查项 | 说明 |
|--------|------|
| 金额/预算 | 技术标中禁止出现任何金额、预算、报价描述 |
| 我方/我们 | 改用"将""项目组""本方案" |
| 本章小结/总结 | 章节正文写完即结束，禁止添加总结段 |
| 通用积极结论 | "未来光明""激动人心""迈向新台阶"等一律删除 |
| 虚假范围 | "从X到Y"结构中 X、Y 不在同一维度时删除 |
| 夸大象征意义 | "标志着""见证了""彰显了"等删除 |

### 快速检查清单

- [ ] 连续三个句子长度相同？打断其中一个
- [ ] 段落以简洁单行结尾？变换结尾方式
- [ ] 揭示前有破折号？删除
- [ ] 使用了"此外""然而"等连接词？考虑删除
- [ ] 三段式列举？改为两项或四项
- [ ] 出现了金额描述？删除
- [ ] 出现了"本章小结"？删除
- [ ] 项目名称准确引用？检查

## 五、处理流程

1. 红旗词扫描 — 查找替换上述所有模式
2. 结构检查 — 打破对称模式，变化段落长度
3. 语气自然化 — 缩短句子、口语化、加转折
4. 标书专项检查 — 金额、人称、章节总结等
5. 默读检验 — 读起来像能干的同事写的就对了
